How it works

Point agents at it

Set ANTHROPIC_BASE_URL=http://agentgate/anthropic for Claude Code or OPENAI_BASE_URL=http://agentgate/openai/v1 for Codex. Nothing else changes for the engineer.

The tailnet is the login

agentgate runs as a tsnet node. Each call is attributed with WhoIs on the caller's Tailscale IP, so there are no per-person API keys to hand out or revoke.

Guardrails before the model

Every request body is scanned for credentials (cloud keys, tokens, private keys) and blocked or redacted before it leaves the network. Responses stream through untouched.
